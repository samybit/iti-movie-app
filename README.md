# Quick Start

### 1. Clone & Install

```bash
git clone https://github.com/samybit/movie-app.git
cd iti-movie-app
npm install
```

### 2. Set Up Environment

Create a `.env` file in the root folder and add your TMDB API key:

```env
VITE_TMDB_API_KEY=your_api_key_here
```

### 3. Run Development Server

```bash
npm run dev
```
